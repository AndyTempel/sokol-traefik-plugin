# Third-party notices

The Sokol Traefik plugin has no third-party runtime Go module dependencies. It
uses only the Go standard library so it remains compatible with Traefik's
interpreted plugin environment.

The default page falcon is adapted from the public-domain Openclipart
`GDI-CnC3-logo.svg` artwork, as documented in the project README.

The test harness downloads pinned development-only copies of Yaegi and Traefik.
Those tools are not included in the plugin artifact or interpreted runtime.
